Content Generator - Genie Prompt Lab
1. Project Overview

Genie Prompt Lab is a web-based AI content generator that allows users to create structured text outputs based on prompts. The system helps users quickly generate ideas, summaries, and written content using an AI-powered interface.

The application is designed to simplify content creation and improve productivity by turning simple user inputs into meaningful, structured outputs.
